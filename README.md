# Event Ticketing System

A terminal-based event ticketing and booking system built with JavaScript and Node.js.

## Features

- Create events with capacity limits.
- Manage ticket tiers and prices.
- Confirm bookings with unique references.
- Prevent bookings when tickets are sold out.
- Maintain a first-in, first-out (FIFO) waitlist.
- Cancel bookings and promote the next eligible customer.
- Find bookings quickly using a JavaScript Map.

## Getting Started

Make sure Node.js is installed.

Run the demo:

```bash
npm run demo
```

Run the booking lookup benchmark:

```bash
npm run benchmark
```
